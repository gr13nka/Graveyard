# Indigo line-art graveyard — frozen snapshot

This is the cool-indigo, stroke-only version of the graveyard as it stood on
2026-08-18, kept whole and runnable so it can be looked at beside the flat
sunset rebuild.

**It is a snapshot, not a maintained variant.** Nothing here is wired to the
project's current `css/`, `js/` or `doodles/` — it carries its own copies. Do
not edit it to "keep it in sync"; if the indigo direction is ever revived,
branch from commit `38952b1` instead.

Serve the project root over http and open `/variants/indigo/`.
`file://` silently breaks every ES module.
