# Хэндоф: идея «кроссплатформенный Time Machine на базе kopia»

Разбор по скиллу `filter-business-idea`, 23.07.2026. Скилл выдаёт флаги, не вердикт — решение за автором. Порог успеха: **≥ 1000 €/мес**.

## Входные факты (от автора)

- Идея: бэкап «как Time Machine, но для всех платформ», на базе kopia; «легко, понятно, красиво» — в отличие от UI kopia.
- Сегмент (ответ автора): **«обычный пользователь»**; монетизация: **подписка без хранилища**; каналы: HN/Reddit + поисковый спрос.
- Эвиденциальность боли: **сам искал** (n=1), формулировка боли — «со всех устройств, с любой ОС, на мой личный сервер».
- «Time Machine» — товарный знак Apple: как название не годится, только как метафора.

## Главный структурный вывод

Два независимых разрыва:

1. **Идея уже реализована дословно и раздаётся бесплатно**: BlinkDisk — форк kopia с человеческим UI, кроссплатформенный, BYO-storage бесплатно, монетизация только сторожем ($3–12/мес, 15 ГБ бесплатно), запуск на HN в июне 2026. Показательно: даже прямой аналог не рискнул брать деньги за сам GUI.
2. **Ответы автора описывают три разных бизнеса**: «обычный пользователь» ↔ «подписка без хранилища» (ему негде хранить) ↔ «HN/Reddit» (там технари). Любые два из трёх несовместимы. Заявленная боль (личный сервер) — prosumer-боль, не боль заявленного сегмента.

## Денежная улитка

Не собрана. «Заплатит, потому что красиво и легко» рвётся о факт: красивое и лёгкое в нише бесплатно (BlinkDisk, Duplicati, KopiaUI, TimeShift, Cronopete, Vorta), а стораж — единственное, за что платят, — в модель не входит.

## Красные флаги

- 🔴 **BlinkDisk = эта идея, уже запущенная**. ЕСЛИ точный аналог отдаёт GUI бесплатно и монетизирует стораж, ТО подписка за GUI не дойдёт до 1000 €/мес, ПОТОМУ ЧТО сегмент BYO-storage — технари, умеющие находить бесплатное; «красивость» не создаёт ров при нулевой цене переключения.
- 🔴 **Ниша плотно закрыта живыми бесплатными**: Duplicati (кроссплатформенный GUI), KopiaUI (kopia активна), TimeShift, Cronopete (клон TM для Linux), Vorta, Arco (Borg) + встроенные File History / Windows Backup.
- 🟠 **Tarpit ×2**: «то же, но красивее» против бесплатного и встроенного + тонкая обёртка над OSS без рва (kopia может улучшить UI; форк может сделать любой — BlinkDisk уже сделал).
- 🟠 **Сегмент ≠ модель ≠ канал** (см. главный вывод).
- 🟡 **Товарный знак** «Time Machine».

## Kill-критерии (зафиксированы до ресёрча) и результаты

1. ≥2 мёртвых GUI-обёрток над kopia/restic/borg → «красивого GUI достаточно» опровергнута. **Не подтверждён — найдено хуже: живые бесплатные.**
2. Живой бесплатный кроссплатформенный GUI существует → звено «заплатит мне» порвано для технарей. **Сработал** (Duplicati, BlinkDisk free).
3. Нет следов оплаты софта-без-стоража «обычными» → связка порвана. **Сработал** (в пределах поиска).
4. SEO-выдача занята бесплатным/встроенным → канал мёртв. **Сработал частично** (объёмы запросов не мерились).

## Гипотезы «почему не сработает» (статусы)

- **H1**: обычные пользователи считают облачный sync бэкапом и не ищут другого. *Косвенно подтверждена (звено 2).*
- **H2**: технари не платят за GUI — платят за стораж или не платят. *Подтверждена (BlinkDisk/Vorta/Duplicati бесплатны).*
- **H3**: ров нулевой — kopia/форки закрывают нишу сами. *Подтверждена (BlinkDisk уже сделал ровно это).*

## Следующая самая дешёвая проверка реальностью

**Установить BlinkDisk на свои машины и свой сервер** (один вечер, автор сам — носитель боли):
- решает боль → бизнес-идея закрыта, личная проблема решена бесплатно — тоже победа;
- бесит/ломается → задокументировать каждую точку «бесит» = единственная честная дифференциация, проверенная на живом пользователе, и материал для решения: PR в BlinkDisk/kopia или своё.

## Адаптации (что чинит / ценой чего)

- **A. «Личный сервер в один клик»** — красивый self-hosted приёмник бэкапов (клиенты + one-click deploy серверной части); честный сегмент = self-hosted комьюнити, реальная боль автора. Чинит звенья 1–2 ценой сужения рынка.
- **B. Storage-included** — единственная модель, за которую в нише платят; цена: бизнес облачного провайдера, конкуренция с Backblaze, другой класс затрат и ответственности.
- **C. Контрибуция** — улучшать KopiaUI/BlinkDisk: чинит боль и репутацию, денег не приносит (признать честно).
