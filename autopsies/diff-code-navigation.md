# Диф с навигацией по коду (ctrl+click → определение / ссылки, не покидая диф)

> Kill-критерии: сработало 0 из 5 полностью (2 частично, 1 не проверен) · Флаги: 🔴 1 / 🟠 4 / 🟡 3
> Дата разбора: 2026-07-24. Порог успеха: ≥ 1000 €/мес.
> **Ревизия 2026-07-25:** звено 6, K1 и K5 изменились, добавлена оценка опенсорс-разворота —
> см. раздел «Ревизия 2026-07-25». Итоговые флаги после ревизии: 🔴 1 / 🟠 2 / 🟡 4.

Вход: «инструмент, в котором ctrl+click работает прямо в дифе — перейти к определению, посмотреть,
где определено и кем вызывается, не переключаясь в редактор. Все найденные редакторы сначала
выкидывают в окно редактора уже БЕЗ дифа».

Уточнено на этапе 1 (`мне сказали`, от автора):
- форма: **есть работающий прототип, отдельное веб-приложение**;
- сегмент: **диф от AI-агента** (Claude Code / Cursor), т.е. локальные изменения до коммита;
- пробовал VS Code Peek (Alt+F12), GitHub code navigation, JetBrains diff viewer — «не переходят
  по символу, на который жму с контролом, они этого не умеют»;
- кто платит: **не думал об этом**.

## Ревизия 2026-07-25

Автор оспорил тезис «конкуренты это умеют» и заявил готовность сделать продукт **опенсорсным
расширением под VS Code**. Обе вещи проверены; обе меняют выводы, поэтому фиксирую эволюцию,
а не переписываю первую версию.

### Поправка по существу: звено 6 было оценено слишком мягко

В версии от 24.07 я засчитал GitHub code navigation как «фича существует» и на этом основании
понизил звено 6 до 🟠. Проверка **поведения**, а не наличия, даёт другую картину:

- **GitHub:** всплывашка по символу появляется прямо в дифе, но переход уводит.
  Дословно из анонса фичи: *«clicking on a definition or reference will take you to the code browser
  for the pull request's head branch»*. То есть GitHub делает ровно то, на что жалуется автор:
  показывает, а при переходе выбрасывает из дифа.
- **VS Code:** механизм подтверждён. microsoft/vscode-go#1204 — *«go-to-definition doesn't work in
  diff editor for staged files»*, там же: *«previously it was possible to go to definitions directly
  from the right-hand pane of the diff editor… but this is no longer the case»*.
  Корень: стороны дифа отдаются по URI схемы `git:` — read-only виртуальные документы;
  language server отвечает для `file://` и об этих документах не знает.
- **Локальные вьюеры** (difit, diffity, revdiff, codiff, diffai, Diffsmith): навигации нет вовсе.
- **Sourcegraph browser extension** — единственный, кто даёт code intelligence именно на дифах,
  и остаётся ближайшим аналогом. Контекст: в декабре 2025 Sourcegraph и Amp разделились на две
  компании (основатели ушли в Amp Inc.), в июне 2025 закрыты тарифы Cody Free и Cody Pro —
  индивидуальный разработчик перестал быть их целевым пользователем.
- **VS Code Marketplace:** расширения с навигацией внутри дифа не найдено. Есть визуализация
  (`caponetto.vscode-diff-viewer`) и семантический диф (`SemanticDiff`) — другое.

**Эволюция severity звена 6: 🔴 → 🟠 (24.07) → 🟡 (25.07).**
Причина последнего перехода: заявленный разрыв «никто не даёт навигацию, не покидая диф»
подтверждён источниками, а не только опытом автора. Звено 6 больше не выглядит порванным
о существующие бесплатные решения — оно остаётся 🟡 только потому, что «ниша свободна»
и «за это платят» — разные утверждения, и второе по-прежнему не проверено.

**K1 — переоценка: НЕ сработал** (в версии 24.07 стоял «частично сработал»).
Продукта, который даёт go-to-definition/find-references, не покидая диф, не найдено ни в одной
из форм. Формулировка автора подтверждена.
**K5 — снимается** при переходе на расширение: код не покидает машину, возражение безопасности исчезает.

### Что даёт опенсорс-расширение под VS Code

**Технически — да, выполнимо, и радикально дешевле веб-приложения.**
`предполагаю` (стандартный API, проверяется за вечер): расширение регистрирует
`DefinitionProvider` / `ReferenceProvider` с селектором по схеме документа (`{scheme: 'git'}`),
переводит позицию в соответствующую позицию рабочего `file://`-документа, делегирует запрос
через `vscode.executeDefinitionProvider` / `vscode.executeReferenceProvider` и показывает результат
через `editor.action.peekLocations` — peek-виджет раскрывается **поверх дифа**, диф остаётся на экране.

Тем самым чужой LSP-индекс переиспользуется, а не строится заново. Что остаётся сложным:
- маппинг позиций между ревизией и рабочим файлом (нужно разбирать ханки);
- **символ, которого больше нет в HEAD** — левосторонние удаления. Здесь чужим индексом
  не обойтись, нужен индекс предыдущей ревизии. Это самый дорогой и самый защитимый кусок.

**Что чинится в цепочке:**

| Звено | Было | Стало | Почему |
|---|---|---|---|
| 7 (себестоимость) | 🔴 серверная индексация — постоянный compute на пользователя | 🟡 | вычисления на машине пользователя, чужим LSP; €0/юзер |
| 8 (переход) | 🟠 веб-форма против «код не покидает машину» | ✅ | код никуда не уходит; установка вместо загрузки репозитория |
| 4 (канал) | 🟡 канал не назван | ✅ | Marketplace — канал с измеримыми установками, ведёт точно в сегмент |
| 6 (почему мне) | 🟠 | 🟡 | см. выше |

**Что НЕ чинится и что появляется нового:**

**🔴 Звено 3 не меняется вообще, а формально ухудшается.** Раньше цена категории была €0 из-за
конкурентов; теперь она €0 в том числе и по собственному решению.
> ЕСЛИ инструмент бесплатен и открыт, ТО 1000 €/мес не появится из донатов,
> ПОТОМУ ЧТО донат — функция размера аудитории, а не полезности: при среднем донате €5 требуется
> 200 донатящих **каждый месяц**, тогда как типичная доля донатящих от установок в dev-тулинге
> **с источником не найдена** — то есть даже прикинуть требуемый охват не на чем.

**🟠 Платформенное поглощение усиливается, а не ослабевает.** Аккуратное расширение на несколько
сотен строк, чинящее очевидный пробел в diff-редакторе, — ровно тот класс вещей, который VS Code
втягивает в ядро (и issue #1204 показывает, что в ядре об этом знают).
> ЕСЛИ фича мала, очевидна и открыта, ТО отдельного бизнеса из неё не вырастет,
> ПОТОМУ ЧТО стоимость её повторения для владельца платформы ниже стоимости покупки или партнёрства,
> а открытый код делает повторение ещё дешевле — сам показывает как.
> При опенсорсе это не проблема, а цель; проблемой становится только при попытке монетизации позже.

**🟡 Новое: опенсорс проверяет левую половину цепочки и не проверяет правую.**
Установки в Marketplace измеряют звенья 1, 2, 5 (боль реальна / осознана / решение лучше текущего)
и не измеряют 3, 6, 7 (платят / платят мне / сходится). Это законная **последовательность**
(сначала дёшево измерить боль, потом искать деньги) и нелегитимная **замена** вопроса о деньгах.
Различие проверяется одним вопросом к себе: назван ли заранее момент, когда установки
конвертируются в проверку оплаты, — или «потом разберёмся».

## Денежная улитка

**Исходная (из описания идеи) — НЕ собирается:**

> ЕСЛИ я сделаю дифф-вьюер с навигацией внутри дифа
> ТО разработчик заплатит ‹?›
> ПОТОМУ ЧТО переключение в редактор неудобно

Обоснование тавтологично: «потому что» пересказывает продукт другими словами. Третьего элемента нет.

**Пересобранная после этапа 1 — собирается, но держится на непроверенном звене:**

> ЕСЛИ я сделаю локальный вьюер агентских дифов с go-to-definition / find-references внутри дифа
> ТО разработчик, ежедневно принимающий диффы AI-агента в незнакомом ему коде, заплатит ‹модель не выбрана›
> ПОТОМУ ЧТО агент правит файлы, которых нет в его голове, а решение «принять / откатить» требует
> знать, кто вызывает изменённый символ — и сегодня этот вопрос обслуживается только
> переключением в редактор, где дифа уже нет, т.е. ценой потери позиции в ревью

Третий элемент есть: **потеря контекста ревью при уходе за ответом**. Это не пересказ продукта.
Чего в улитке нет и что рвёт её на практике: величина потери не измерена (секунды? минуты?),
а именно от неё зависит, конвертируется ли раздражение в деньги.

### Звено 3 — разбор (двойственное)

**За (бюджет рядом существует):** команды платят за ревью-тулинг сегодня —
CodeRabbit Pro $24–30/user/мес, Graphite ~$24–30/user/мес, Greptile $30/seat/мес (50 ревью в seat).
Но платят за **AI-комментарии к коду**, а не за навигацию/UX.

**Против (в его собственной категории платят почти нулю):** «локальный вьюер агентских дифов» —
переполненная бесплатная ниша по состоянию на 2026:
difit (yoshiko-pg), diffity (nilbuild), diffty (darccio), codiff, revdiff (umputun), diffai,
Claude Diff Viewer (VS Code Marketplace). Все открытые/бесплатные.

**Единственный найденный платный в категории: Diffsmith** — «code review studio» для локальных
изменений от Claude Code / Cursor / Codex, 100% offline, **разовая покупка = пожизненный доступ**.
Это факт в пользу того, что за категорию в принципе платят — и одновременно факт о том,
в какой форме: one-time, не подписка.

### Звено 6 — эволюция severity: 🔴 → 🟠

- **Начальная 🔴:** функция выглядит уже реализованной и бесплатной. GitHub code navigation работает
  в PR прямо во вкладке Files changed (hover по символу → Go to definition / Find references),
  21 язык, tree-sitter, без какой-либо настройки репозитория. Sourcegraph browser extension даёт
  hover / go-to-definition / find-references / find-implementations **на файлах и дифах**
  GitHub, GitHub Enterprise, GitLab, Phabricator, Bitbucket — бесплатно и с открытым кодом, жив
  (сворачивали в 2022 экосистему *Sourcegraph extensions*, а не сам браузерный аддон).
- **Понижение до 🟠:** обе эти вещи покрывают **веб-PR на код-хостинге**. Сегмент автора —
  **локальный агентский диф до коммита**, куда ни GitHub, ни Sourcegraph не достают, а ни один из
  шести локальных вьюеров (см. выше) LSP-навигации, судя по их описаниям, не имеет.
  Дифференциатор формально свободен. Это честное различение, оно и спасает звено от чистого 🔴.
- **Почему не ✅:** свободен ≠ оплачиваем; и владеть этой фичей «по праву» будут Cursor / VS Code /
  Claude Code, у которых уже есть и LSP-индекс, и экран с дифом.

## Арифметика на салфетке

**Сверху вниз** — что означает 1000 €/мес при разных моделях:

| Модель | Что требуется |
|---|---|
| €19 разовая (по образцу Diffsmith) | ~53 покупки **каждый месяц, вечно, с нуля** |
| €10/мес подписка | 100 активных подписчиков + компенсация оттока (типичный отток в нише — **не найден с источником**, не подставляю) |
| €24/seat B2B | ~42 места ≈ 4–8 команд |
| open source + донаты | доля донатящих в дев-тулинге с источником **не найдена** → не считаю |

**Снизу вверх** — не считается: канал не назван, ёмкость неизвестна.
Что можно посчитать — **ТРЕБУЕМЫЙ** трафик (не достижимый, а необходимый):
53 покупки/мес при конверсии лендинга 1 % → ~5 300 визитов/мес; при 0,5 % → ~10 600 визитов/мес.
Типичная конверсия лендинга dev-tool **не найдена с источником** — сравнивать не с чем, число оставлено сырым.

**Структурная проблема, видная прямо здесь:** Show HN / Product Hunt дают **разовый всплеск**,
а разовая покупка требует **вечного потока**. Модель one-time + запусковый канал не стыкуются:
после спада запуска выручка обнуляется, и её нечем воспроизвести.

**Себестоимость** (в отличие от конкурентов): чтобы дать навигацию, нужен индекс кода.
Если он серверный — это постоянный compute на каждого пользователя, тогда как все шесть бесплатных
конкурентов чисто клиентские и стоят авторам €0 за пользователя. Маржа на €10/мес при серверной
индексации не посчитана и может быть отрицательной.

**Платёжная досягаемость:** индивидуальные разработчики — карты есть, вопрос не в возможности,
а в готовности. B2B — закупка через компанию, появляется вопрос «кто внутри будет против»
(здесь: безопасность, из-за загрузки исходников).

## Что ЕЩЁ нужно, кроме продукта

- **Индексация под каждый язык** — самая дорогая часть; tree-sitter даёт дешёвый вариант ценой точности,
  полноценный LSP — ценой инфраструктуры на язык.
- **Левая (удалённая) сторона дифа** — принципиально сложнее правой: нужен индекс *предыдущей* ревизии.
  Это же и самый защитимый кусок (см. адаптации).
- Монорепо и большие репозитории — где навигация и нужна, там индекс и тяжёлый.
- Приватность: если сервер — для B2B понадобится минимум внятная security-страница, дальше SOC 2.
- Платёжка: Stripe / Paddle, НДС в ЕС (Paddle как merchant of record снимает это, беря процент).
- Поддержка + догоняющие обновления под изменения Claude Code / Cursor.

## Красные флаги

**🔴 Цена категории установлена в €0 шестью живыми бесплатными конкурентами.**
> ЕСЛИ в категории «локальный вьюер агентских дифов» уже 6+ живых бесплатных инструментов
> (difit, diffity, diffty, codiff, revdiff, diffai — все 2026), а единственный найденный платный
> продаётся разовой лицензией,
> ТО проект не дойдёт до 1000 €/мес на подписке,
> ПОТОМУ ЧТО цена в голове покупателя формируется сравнением с ближайшим доступным аналогом,
> а не себестоимостью разработки: чтобы человек платил €10/мес за то, что рядом лежит даром,
> нужна не «фича лучше», а невозможность получить приемлемый результат бесплатно —
> а он получается, просто с alt-tab.

**🟠 Монетизация не продумана, при том что прототип уже написан.**
> ЕСЛИ продукт сделан раньше, чем назван платящий,
> ТО дойти до 1000 €/мес мешает уже принятое решение,
> ПОТОМУ ЧТО форма (веб-приложение с индексацией) зафиксировала и себестоимость, и способ
> дистрибуции до проверки, кто достаёт кошелёк — а переделывать форму дороже, чем выбрать её.

**🟠 Веб-форма против доминирующего в нише ожидания приватности.**
> ЕСЛИ конкуренты продают «код не покидает машину» как главный аргумент, а моё решение требует
> отдать исходники на сервер ради индексации,
> ТО B2B-сегмент — единственный с доказанным бюджетом ($24–30/seat) — не откроется,
> ПОТОМУ ЧТО решение о выгрузке кода принимает не разработчик, а безопасность; это отказ
> по процессу, а не по цене, и скидкой он не лечится.

**🟠 Платформенное поглощение.**
> ЕСЛИ навигация в дифе — естественная часть review-UI редактора или агента,
> ТО отдельный продукт не удержит подписку,
> ПОТОМУ ЧТО Cursor / VS Code / Claude Code уже владеют и LSP-индексом, и экраном с дифом:
> им эта фича стоит недель работы, а для отдельного продукта она — единственная причина существовать.

**🟠 Модель one-time не стыкуется с запусковым каналом.**
> ЕСЛИ выручка разовая, а канал — Show HN / Product Hunt,
> ТО 1000 €/мес не станет регулярными,
> ПОТОМУ ЧТО запуск даёт всплеск, а разовая покупка требует вечного потока новых людей:
> после спада запуска воспроизводить выручку нечем.

**🟡 Эвиденциальность боли: n=1 плюс один найденный feature request.** Проверка дешёвая — см. чек-лист.
**🟡 Себестоимость индексации на пользователя не посчитана.** Считается за вечер на своём же прототипе.
**🟡 Канал не назван,** хотя объективно существует и ведёт ровно к сегменту.

## Гипотезы «почему не сработает» и их статус

1. **«Фича уже есть бесплатно, а опыт автора — про частный случай»** — 🟠 частично подтверждена.
   Для веб-PR подтверждена (GitHub code nav, Sourcegraph). Для локального агентского дифа —
   не подтверждена: таких инструментов не нашёл. Остаётся вопрос, почему у автора не сработали
   VS Code Peek и GitHub nav — это разница между «не умеет» и «не сработало в моём случае»,
   и она напрямую влияет на размер рынка (если умеет, но люди не знают — это рынок образования,
   отдельный дорогой бизнес).
2. **«Боль реальна, но это трение, а не блокер»** — не опровергнута, **главная угроза**.
   Экономия секунд редко конвертируется в подписку; вся категория стоит €0 именно поэтому.
3. **«Платформа поглотит фичу»** — не опровергнута, риск структурный.
4. **«Веб-форма несовместима с приватностью корпоративного кода»** — усилена ресёрчем:
   конкуренты явно продают offline как преимущество.
5. **«Платят не за то, что дорого делать»** — не опровергнута: самая дорогая часть (индексация)
   для пользователя невидима, он оценивает сэкономленные секунды.

## Следующая самая дешёвая проверка реальностью

**Предпродажа прототипа, который уже написан.** Не опрос, не «интересно?», а счёт.
Работает потому, что прототип уже есть — стоимость проверки близка к нулю, а проверяет она
разом звенья 3, 5, 6 и 7.

Механика: лендинг на одну страницу + 30-секундная гифка ровно одного момента (ctrl+click по символу
внутри дифа → определение появляется, диф остаётся на экране) + кнопка оплаты с реальной ценой
(€19 one-time, ранний доступ). Пост в r/ClaudeAI и Show HN.

Текст первого сообщения:

> **Show HN: <имя> — ctrl+click в дифе агента: определение и все вызовы, не покидая ревью**
>
> Я ревьюю диффы Claude Code каждый день. Каждый раз, когда надо понять, кто вызывает изменённую
> функцию, я ухожу в редактор — и теряю позицию в дифе, к которому потом возвращаюсь заново.
> Существующие локальные вьюеры (difit, diffity, revdiff) показывают диф красиво, но по символам
> не ходят. GitHub умеет ходить по символам, но только в PR — в локальный диф до коммита он не смотрит.
>
> Я сделал вьюер, где ctrl+click по символу прямо в дифе открывает определение и список вызовов,
> не уводя с экрана. Работает и на удалённых строках: можно спросить «а кто вызывал это ДО изменения».
>
> €19, разовая покупка, ранний доступ: <ссылка>. Что не работает: <честный список ограничений>.

**Что считать результатом.** Не апвоуты и не «круто, поставлю звезду» — это ответ на вопрос
«нравится», а не «заплатят». Считать только оплаты.

**Заранее назначенное число (иначе результат будет истолкован задним числом):**
если 500+ уникальных посетителей лендинга дают **0 покупок** — звено 3 подтверждено порванным:
за эту функцию не платят, она стоит ровно €0, сколько бы людей ни сказали, что она полезна.
Если покупок 5–10 — сигнал есть, но модель one-time всё ещё не даёт регулярности:
следующий вопрос будет не «делать ли», а «чем воспроизвести поток».

## Возможные адаптации

| Адаптация | Какое звено чинит | Ценой чего |
|---|---|---|
| **Навигация по левой (удалённой) стороне дифа** — «кто вызывал это ДО изменения». Ни GitHub, ни Sourcegraph, ни локальные вьюеры этого не делают: нужен индекс предыдущей ревизии | 6 — единственный кусок, который защитим и который платформам дорого повторить | Узость: нужна не всем и не каждый день; звено 1 сужается |
| **Сменить форму на локальный бинарник/плагин** (как difit / revdiff), монетизация one-time (как Diffsmith) | 8 (приватность) и 6 (снимает возражение безопасности) | Ломает звено 9: разовая покупка требует вечного потока покупателей |
| **B2B-разворот:** та же навигация как обогащение PR-ревью для команд | 3 и 7 — там бюджет доказан ($24–30/seat) | Лобовая конкуренция с бесплатными GitHub code nav и Sourcegraph; появляется цикл продажи |
| **Не продукт, а фича:** отдать навигацию в один из шести существующих вьюеров (PR в difit/diffity), а деньги искать в другом месте | Убирает вопрос монетизации целиком | Это не бизнес; но самый дешёвый способ узнать, нужна ли фича людям, у которых уже есть аудитория |

## Что сильного в идее (чтобы не потерялось на фоне флагов)

- Звено 9 (регулярность) — сильное: ревью агентских дифов растёт как ежедневная практика.
- Канал ↔ сегмент сходятся точно, это редкость и это дёшево.
- Дифференциатор реальный: шесть конкурентов делают вьюер, навигацию не делает никто.
- Прототип уже есть → стоимость следующей честной проверки близка к нулю.

Порвано не «идея», а связка «за это платят деньгами» при цене категории €0.
